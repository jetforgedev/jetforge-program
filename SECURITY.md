# Security

If you find a vulnerability in the JetForge program, please report it privately so it can
be fixed before it is exploited.

- Email: **support@jetforge.io** (subject: "Security")
- Please do **not** open a public GitHub issue for security problems.

Include the affected instruction, the steps to reproduce, and the impact. We'll acknowledge
your report and keep you updated while it's fixed. Upgrades to the program require approval
from a 2-of-3 multisig.

Never share private keys or seed phrases with anyone, including people claiming to be from
JetForge. JetForge will never ask for them.
